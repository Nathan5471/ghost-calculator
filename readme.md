# Ghost Calculator

## Description

Your goal is to make a complex equation to reach a target number. If you have to press backspace, clear, or you get an error, your score will reset. There is also a secret pumpkin game you can play, try to find it in the start menu.

## How to Play

Click the play button and start using the calculator to make an equation that equals the target number. Make it as complex as possible to earn the most points possible.

## Technologies

This was built using Godot. The calculator uses the Shunting Yard Algorithm to parse the inputed string.
